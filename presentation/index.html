🌐 Что такое GitHub Pages?

GitHub Pages — это бесплатный хостинг от GitHub, который публикует файлы из репозитория как настоящий сайт в интернете.


  • Работает с HTML, CSS и JavaScript
  • Сервер не нужен — GitHub всё делает сам
  • Сайт появляется автоматически после включения опции
  • Адрес: https://username.github.io/repo-name/

Игровой хаб, который ты только что видел — и есть пример GitHub Pages!

Слайд 2 / 10

🔓 Репозиторий должен быть публичным

GitHub Pages работает только с публичными репозиториями на бесплатном аккаунте.


  • 🟢 Public — виден всем, GitHub Pages включается
  • 🔴 Private — скрыт, GitHub Pages требует платный план

При создании репозитория всегда выбирай Public!

GitHub → New repository
→ Repository name: my-project
→ ✅ Public ← вот это важно!
→ Add a README file ✅
→ Create repository
Слайд 3 / 10

📛 Как назвать репозиторий?

У GitHub Pages есть два режима:

Режим 1 — Личный сайт (один на аккаунт)
Репозиторий: username.github.io
Адрес сайта: https://username.github.io/

Пример: maxzru.github.io → https://maxzru.github.io/
Режим 2 — Проектный сайт (наш случай)
Репозиторий: любое-имя (например: github_pages)
Адрес сайта: https://username.github.io/любое-имя/

Пример: github_pages → https://maxzru.github.io/github_pages/

Слайд 5 / 10

🏠 index.html — входная дверь

Когда браузер открывает папку, он автоматически ищет index.html — это главный файл страницы.

URL без имени файла:
https://site.com/games/tetris/
→ открывает: games/tetris/index.html

Корень репозитория:
https://site.com/
→ открывает: index.html в корне

Поэтому называй главные файлы каждого раздела index.html — тогда URL будет коротким и красивым!

Слайд 6 / 10

🔗 Относительные пути

В HTML-файлах ссылки должны быть относительными — без http://. Это важно, чтобы сайт работал и локально, и на GitHub!

Из корня (index.html):
<link href="css/style.css">
<a href="games/tetris/">Тетрис</a>

Из games/tetris/index.html:
<link href="../../css/style.css">
<a href="../../index.html">← Назад</a>

.. означает «подняться на одну папку выше»
Слайд 7 / 10

⚙️ Как включить GitHub Pages?

Шесть шагов в настройках репозитория:

1. Открой свой репозиторий на GitHub
2. Нажми ⚙️ Settings (в верхнем меню)
3. В левой панели найди раздел Pages
4. Source: выбери Deploy from a branch
5. Branch: main  |  Folder: / (root)
6. Нажми Save

Через 1–3 минуты сайт появится. GitHub покажет его адрес на той же странице Settings → Pages.

🌍 Адрес сайта

GitHub автоматически создаёт адрес по шаблону:

https://твой-логин.github.io/имя-репозитория/

Пример для этого проекта:
https://maxzru.github.io/github_pages/

Тетрис будет доступен по:
https://maxzru.github.io/github_pages/games/tetris/

Этот адрес можно отправлять друзьям — сайт увидит любой человек в интернете!


После каждого git push сайт обновляется автоматически (за 1–2 минуты).

🎉 Итого — главное за одну минуту

  • GitHub Pages — бесплатный хостинг прямо внутри GitHub
  • Репозиторий должен быть Public
  • Главный файл каждого раздела называй index.html
  • Используй относительные пути для ссылок (../../css/style.css)
  • Включается в Settings → Pages → main / root → Save
  • Обновляется автоматически после каждого git push

Теперь у тебя есть всё для создания своего сайта! 🚀
