# 🎮 Игровой Хаб — учебный проект GitHub Pages

Учебный проект для изучения **GitHub Pages**: три мини-игры на JavaScript и интерактивная HTML-презентация о том, как всё устроено.

Целевая аудитория: школьники 12–14 лет.

---

## 🌐 Как открыть сайт

После включения GitHub Pages в настройках репозитория сайт будет доступен по адресу:

```
https://maxzru.github.io/github_pages/
```

Как включить: **Settings → Pages → Branch: main / root → Save**

## 🕹️ Игры

### 🟦 Тетрис
Классический тетрис: 7 фигур, очищение рядов, нарастающий темп.

| Клавиша | Действие |
|---------|----------|
| ← → | Двигать фигуру |
| ↑ | Повернуть |
| ↓ | Ускорить падение |
| Пробел | Сбросить вниз |
| R | Перезапуск |

### 🐍 Змейка
Классическая змейка: ешь еду, расти, не врезайся в стены и в себя.

| Клавиша | Действие |
|---------|----------|
| ← → ↑ ↓ | Управление |
| R | Перезапуск |

### 🧱 Арканоид
Разбивай кирпичи мячом. Три жизни, рефлекс от платформы зависит от точки удара.

| Управление | Действие |
|------------|----------|
| ← → или мышь | Двигать платформу |
| Пробел / клик | Запустить мяч |
| R | Перезапуск |

## 🔑 Ключевые концепции GitHub Pages

- **Публичный репозиторий** — обязательное условие для бесплатного хостинга
- **`index.html` в корне** — точка входа: браузер открывает его, когда URL заканчивается на `/`
- **Относительные пути** — ссылки вида `../../css/style.css` работают одинаково локально и на GitHub
- **Автообновление** — сайт обновляется через 1–2 минуты после каждого `git push`
